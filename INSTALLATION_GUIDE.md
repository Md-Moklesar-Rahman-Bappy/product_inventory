# Installation Guide

## Product Inventory Dashboard

### Default Super Admin Credentials

| Field    | Value                        |
|----------|------------------------------|
| Email    | `superadmin@superadmin.com`  |
| Password | `Password@123`               |
| Role     | Super Admin (permission=0)   |

**You must change the default password on first login.** The system will force a password change before granting access to the dashboard.

### How the Super Admin Account is Created

The default superadmin is created through **three verified channels**:

1. **Installation Wizard** — When you run the web-based installer (`/install`), the wizard creates the superadmin with the default credentials and `force_password_change = true`.

2. **Database Seeder** — Running `php artisan db:seed` creates (or updates) the superadmin account via `DatabaseSeeder`.

3. **Manual SQL** — For advanced users, the equivalent insert:
   ```sql
   INSERT INTO users (name, email, password, permission, utype, status, email_verified_at, force_password_change, created_at, updated_at)
   VALUES ('Super Admin', 'superadmin@superadmin.com', '$2y$12$...', 0, 'SA', 'active', NOW(), 1, NOW(), NOW());
   ```
   The password hash for `Password@123` is generated by `Hash::make('Password@123')`.

### Security Features

- **Forced Password Change** — `force_password_change` column in `users` table. When `true`, the `ForcePasswordChange` middleware blocks all routes except `/force-password-change` and `/logout`.
- **No Backdoors** — No hidden authentication bypasses, no secret routes, no hardcoded tokens.
- **Visible Account** — The superadmin account is fully visible in the Users management page.
- **Normal CRUD** — The superadmin can be edited, disabled, and deleted by authorized administrators through the standard user management interface.
- **Role Hierarchy**:
  - Super Admin (`permission=0`): Full access, can manage all users
  - Admin (`permission=1`): Can manage categories, brands, products
  - User (`permission=2`): Read-only dashboard access

### First Login Flow

1. Navigate to the application URL
2. Login with `superadmin@superadmin.com` / `Password@123`
3. System redirects to the **Force Password Change** page
4. Enter a new secure password (min 8 chars, uppercase, lowercase, number, special char)
5. Confirm the new password
6. Submit — you will be redirected to the dashboard

### Production Recommendations

After first login:
1. **Change the superadmin password** to a strong, unique value
2. **Update the superadmin email** to a real organizational email
3. **Configure SMTP** for email notifications
4. **Review user roles** and create additional admin accounts as needed
5. **Disable registration** if not needed (the registration route is public by default)
